# Shiloh Fresh Exporters

Website for Shiloh Fresh Exporters, a Kenyan fresh-produce export company.

## Local development

```sh
npm install
npm run dev
```

The app runs at `http://localhost:8080`.

## Build

```sh
npm run build
npm run preview
```

## Contact

Quote and inquiry forms are sent to `sarah@shilohfreshexporters.co.ke`.
